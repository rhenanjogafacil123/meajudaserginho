# Me Ajuda Serginho

Protótipo mobile de atendimento ao cidadão para registro e acompanhamento de problemas urbanos.

## Funcionalidades

- Registro de ocorrência por categoria
- Foto, vídeo ou galeria no celular
- Geolocalização do navegador
- Endereço manual
- Descrição e ponto de referência
- Geração de protocolo
- Acompanhamento por status
- Persistência local com localStorage
- Interface mobile-first / PWA demonstrativa

## Rodar localmente

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

> Protótipo demonstrativo, sem backend.
